For entertainment purposes I made a simple fake lottery ticket generator using Java Swing. The application asks the user to input a Us name. S. the state. Three randomly generated numbers and a state label are printed on the ticket if the input corresponds to one of the 45 states with official lotteries. The program still prints a ticket with no state symbol to indicate that there isnt an official lottery if the input is one of the five states without one or isnt recognized.
